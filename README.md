# A longitudinal perspective of the European energy strategy

Analysis of Europen energy statistics, based on data from:

- https://energy.ec.europa.eu/data-and-analysis/eu-energy-statistical-pocketbook-and-country-datasheets_en#country-datasheets
- https://data.jrc.ec.europa.eu/dataset/919df040-0252-4e4e-ad82-c054896e1641

Prepared for the "Data Science And Digitalisation In The Energy Sector" module,
as part of the MSc in Sustainable Energy Futures at Imperial College London.

### Requirements

- Python
- [uv](https://docs.astral.sh/uv/)

##### To edit the notebook in marimo:

```
uv run marimo edit notebooks
```

##### To run the notebook as a web app:

```
uv run marimo run notebooks/european_power.py
```
